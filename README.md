# Python for Network Security

## About This Repository

This repository documents my practical journey learning Python for network engineering, network automation, and network security.

The goal is to develop practical Python skills that can be applied to network monitoring, device management, security analysis, and automation.

## Learning Areas

- Python programming fundamentals
- Network programming and IP address management
- Network monitoring and troubleshooting
- Network automation using Netmiko
- Network security analysis
- Practical network security projects

## Technologies and Tools

- Python 3.12
- Netmiko
- PyYAML
- Requests
- Pytest
- Git and GitHub
- Cisco Packet Tracer
- GNS3 (planned)

## Security Practices

Security is a core requirement throughout this repository.

- No hardcoded passwords, API tokens, or credentials.
- No private SSH keys or certificates committed to GitHub.
- Sensitive environment files are excluded through `.gitignore`.
- Device configurations and backups are not published.
- Testing is restricted to systems and networks I own or have explicit authorization to assess.
- Scripts are developed with safe defaults and appropriate error handling.
